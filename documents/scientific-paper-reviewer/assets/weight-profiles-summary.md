## How to Use This Table

1. **Identify article type** (step from main SKILL.md instructions)
2. **Find corresponding profile** (1–5 above)
3. **Score criteria** with weights in mind — high-weight criteria carry more significance
4. **Apply calculation** using formula: Σ(Criterion Score × Weight %) / 4.0 × 100%

**Example:** For an empirical paper:
- C7 (Methodology) scored 2/4 → 2 × 0.15 = 0.30
- C9 (Reliability) scored 3/4 → 3 × 0.15 = 0.45
- [continue for all weighted criteria]
- Sum contributions, divide by 4.0, multiply by 100%
