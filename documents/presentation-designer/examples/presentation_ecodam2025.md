## Slide 3. Core Idea of the Solution

```slide:content
+----------------------------------------------------------------+
| Core Idea of the Solution                                      |
|                                                                |
+----------------------------------------------------------------+
| 1. Analytic rubrics as a shared scoring framework.             |
|                                                                |
| 2. Skill based assessment: assessment-specialist and           |
|    subject-domain-specialist.                                  |
|                                                                |
| 3. Human-in-the-loop: AI supports, teacher decides.            |
|                                                                |
| 4. Explainable feedback, logging, transparency.                |
|                                                                |
| 5. Native integration into Moodle workflow.                    |
|                                                                |
|                                                                |
+----------------------------------------------------------------+
```

__Comment:__ How do we solve this problem?

We use a grading rubric, which is a pedagogical tool that provides transparency for students and a structured evaluation method for evaluators.

The AI agent-evaluator must possess at least two distinct skills:

- an assessment specialist skill, providing knowledge on how the assessment should be conducted.
- a subject-domain specialist skill, ensuring deep knowledge of the specific course material.

__Comment:__ The problem defines a hypothesis: Can an essay be graded effectively by an AI agent?

This question means the following:

- if we will evaluate an essay more times, will we obtain the same or apropiate scores?
- Will the AI score be same or apropiate with the human expert score?

__Comment:__ To conclude, I would like to highlight the scientific novelty and practical value of this work.

The primary novelty is the development of a comprehensive framework that integrates ethics, analytic rubrics, and AI design into a single approach.

In terms of practical value, the tool is designed for formative use—offering pre-grading feedback to students and reducing the administrative burden on teachers.

Ultimately, our result shows that automation, when implemented responsibly, does not replace the educator but rather strengthens the overall evaluation process.
